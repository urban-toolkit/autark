# RGB imagery sample

`rgb-imagery.tif` is the unmodified `tests/data/RGB.byte.tif` sample from Rasterio:
https://github.com/rasterio/rasterio/blob/main/tests/data/RGB.byte.tif

Downloaded November 16, 2026. It is a three-band, 791 by 718 geographic raster in WGS 84 / UTM zone 18N (EPSG:32618), with a declared no-data value of zero. The example uses the actual raster bands, not synthetic colors. Source repository license: https://github.com/rasterio/rasterio/blob/main/LICENSE.txt
