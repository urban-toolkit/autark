Urban data analytics with Autark

A hands-on tour of Autark, a serverless toolkit for urban visual analytics that runs entirely in the web browser: spatial data management, GPU computation, 3D maps and linked charts.

Abstract

Building urban visual analytics (VA) systems is often a cumbersome, time-consuming task. They must reconcile heterogeneous data sources, perform expensive computations over city geometry, and coordinate multiple linked views. These systems are traditionally assembled as architectures composed of many independent services, which makes them difficult to deploy, reproduce, and share. Recent browser technologies are changing this picture, bringing analytical databases and general-purpose GPU computation directly to the client.

Autark is a serverless toolkit that occupies this new design space, consolidating spatial data management, GPU-accelerated computation, 3D map rendering, and abstract charts into a single lightweight framework that runs entirely in the web browser. This tutorial presents urban VA through the lens of Autark. We introduce the feature-centric model that unifies data exchange across the toolkit, describe its four modules, and build applications of increasing complexity. It aims to propose the first structured material for building serverless urban visual analytics systems with Autark.

Running it

From the repository root, install the repository dependencies once and start the tutorial:

npm ci
make tutorial

Open the local URL printed by Vite (normally http://localhost:5173). Autark is built from this repository and resolved through its workspace packages, just like the gallery and use cases. All sample data is inside tutorial/data/. The runner supplies autk, d3 and GeoTIFF to editable cells; no import maps or CDN imports are needed.

Cells that load OpenStreetMap try the public Overpass server and fall back to recorded responses in data/osm/. Add ?overpass=offline to skip live Overpass requests. DuckDB extensions may still require network access on first use; this is not a guarantee of fully offline operation.

Autark Compute (and Autark Map) need WebGPU: Chrome or Edge 113 or later work out of the box; Firefox needs Nightly with WebGPU enabled.
