## Must fix before merging

### #119 and #134: overlapping fixes, but not interchangeable

Git reports 11 conflicting files between the heads, including four core plot implementations, both binning presets, and the binning tests. #119 says it carries #134's fixes, but does **not** carry the latest behavior in full. For example, [#134's tick-format test](https://github.com/urban-toolkit/autark/blob/84b5de82/autk-plot/test/tick-formats.test.ts#L102-L106) expects `0.1 + 0.2` to display as `0.3`; [#119's bar formatter](https://github.com/urban-toolkit/autark/blob/de172f0f/autk-plot/src/plots/barchart.ts#L52-L58) returns the raw string when no format is configured. #119 centers axis titles, but it does not contain #134's [`placeAxisTitles` layout pass](https://github.com/urban-toolkit/autark/blob/84b5de82/autk-plot/src/plot-base-interactive.ts#L121-L149) or its regression suite. Run or port the #134 tests for bin edges, missing values, numeric formatting, redraws, and layout on the actual #119 integration tree before closing #134 as superseded.

### #119: public compatibility and release decision

The main `AutkPlot` entry point remains; this is not a blanket removal of the old API. But `run()` is publicly exported and changes its documented behavior from a nonthrowing fallback to registry lookup and output validation that can throw ([main](https://github.com/urban-toolkit/autark/blob/083bf8a/autk-plot/src/transforms/index.ts), [PR](https://github.com/urban-toolkit/autark/blob/de172f0f/autk-plot/src/transforms/index.ts)). The exported transform result union now includes custom results, so consumers relying on exhaustive narrowing need a compatibility check. Public config also gains stricter validation and transform-slot rules; interaction-disabled charts no longer emit click/brush events, intentionally. The concrete chart classes replaced by this PR were not exported at the package root, so their removal is primarily an integration conflict, not by itself proof of a public export break. Check the shipped declarations for changes to the **exported** `PlotBaseData`, `PlotBaseInteractive`, `ResolvedPlotTransform`, and event types; test existing npm consumer code as well as the gallery. Preserve compatibility or document the breaks, migration, and release version. Put the Chrome suite in CI: #119's normal CI workflow does not invoke `test:browser`, even though the standalone suite passed locally.

### #141: rebase on current `main` and decide tooltip ownership

The reviewed head conflicts with `29c5705` in `autk-map/src/map.ts`. Rebase it without losing the already shipped map fixes. Decide whether installing a tooltip may change the layer used for click picking, and whether removing the tooltip should restore that layer and leave separately enabled hover running. Test the chosen behavior on real WebGPU.

### #138: clipping policy changes existing expectations

[GitHub CI](https://github.com/urban-toolkit/autark/actions/runs/44802903793/job/136519341388) failed three assertions in `autk-map/test/fit-bounds.test.ts`, including fitted views and reset after a canvas resize. `Camera.update()` replaces the configured/fitted far plane with `max(wFar, abs(eye.z) * 4)`, and `getFar()` now exposes that value. One existing test expects about `573617`, but receives about `2085881`. #136 and #138 also conflict in `autk-core/src/camera.ts`. Define how the automatic range interacts with explicit/fitted bounds and both orthographic modes; test near/far visibility, resize/reset, tilted views, and renderer consumers of `getFar()`. Don't just update the expected numbers.

### #146: rebase and split before review approval

#146 conflicts even with its declared base (#134). It forked from `621d786` and its old bar-chart formatter does not preserve the final #134 numeric-category behavior. It also conflicts with #143 in `api.ts` and `plot-base-data.ts`; a trial cherry-pick of the first #146-only commit on top of the integrated legacy stack reproduced both conflicts. Separate grouped bars, custom tick labels, and the overlay hook; keep #134's formatting and title layout, and define what happens when several rows share the same category **and** group (the current side-by-side code gives them the same rectangle slot). Test overlays across redraw, resize, and brush gestures.
